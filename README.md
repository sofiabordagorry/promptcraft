# PromptCraft 🧱✨  
**AI-generated Minecraft structures from natural language prompts**

PromptCraft is an experimental project that integrates **Minecraft Java Edition (Fabric mod)** with a **Elixir (Phoenix) backend** powered by LLMs.  
Players can describe a structure in plain language using the `/askAI` command, receive a special “Builder”, and place it in the world to automatically generate the structure.

---

## Features

- `/askAI <description>` command inside Minecraft  
- Backend powered by an LLM (OpenAI-compatible API)  
- JSON-based structure format (palette + layers)  
- A custom block that generates structures when placed  
- Modular, extendable architecture
